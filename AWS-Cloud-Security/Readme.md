# Overview

Welcome to the AWS section of my IT Professional Portfolio.

This repository documents hands-on projects completed in my personal AWS lab environment. Each project is designed to strengthen my understanding of cloud infrastructure, systems administration, automation, and security while developing documentation skills expected in professional IT environments.

Rather than simply following tutorials, every project is documented as an engineering implementation that includes the business problem, objectives, architecture, implementation details, security considerations, lessons learned, and future improvements.

This portfolio is continuously updated as new AWS projects are completed.

# Engineering Philosophy

Every project in this repository is approached as if it were being implemented in a production environment.

The focus is not only on **how** to configure AWS services, but also on understanding:

- Why a security control exists
- What risks it mitigates
- How it integrates with other AWS services
- How it would be improved for production use
